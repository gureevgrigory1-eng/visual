# Корзина — интерактивный дашборд покупок

Vue 3 + D3 7 + Vite. Самостоятельное статическое приложение на реальных данных первой недели. Сначала раскрывается история покупок, в финале открывается отдельный экран дашборда. Данные и 500 изображений включены в проект; сервер данных не нужен.

## Запуск

Требуется Node.js 24 (или совместимый с Vite 7).

```sh
npm ci
npm run dev
```

Откройте адрес, напечатанный Vite. Для разработки нужен HTTP. Готовый `standalone/index.html` можно открыть прямо в браузере: приложение, данные и изображения встроены в документ.

```sh
npm test
npm run build
npm run preview
```

`dist/` — сборка Vue для обычного HTTP-хостинга. `standalone/index.html` — автономная версия с исходными iframe sandbox="allow-scripts" и CSP, переходами, данными и фотографиями. `npm run build` обновляет обе версии. GitHub Pages публикует `standalone/`; приложение работает в подпапке `/visual/`.

## Данные и проверка

`public/data/purchases.json` содержит каталог позиций, строки доставленных заказов и аудит. `public/data/audit.json` — независимые контрольные суммы. Деньги — в целых копейках. Адрес и время доставки исключены из публичных файлов. Остаются даты, идентификаторы заказов и потребительская история, необходимые для анализа.

Исходный CSV: 5849 строк, 961 уникальный заказ, 05.09.2021–29.08.2026. Из анализа исключены 111 строк 17 отменённых заказов. Доставленных: 5738 строк, 944 заказа. Дубликатов, отрицательных значений и пропусков обязательных полей нет. 111 отсутствующих delivered_time относятся к отменённым заказам. Возвратов отдельным статусом нет; скрытые возвраты определить нельзя.

Контроль за всё время: расходы **1 278 791 ₽**, стоимость до скидки **1 304 334 ₽**, экономия **25 543 ₽**, скидка **1,9583174 %**, товары **5244 шт.**, **498** уникальных товаров, **11** категорий. С услугами — 6534 единицы и 500 позиций. Число строк не равно числу заказов или штук.

Все 500 изображений найдены через `items/positions.csv`: 385 точных совпадений и 115 совпадений после документированной замены бренда Груши → Лавки / Груша → Лавка. Используется NFC-нормализация Unicode. Публичные имена картинок — код позиции + расширение; это избегает проблем кириллицы в URL. Картинки не подбираются приблизительно.

Для повторного импорта поместите исходный CSV и items рядом с папкой проекта, затем:

```sh
python3 scripts/prepare_data.py ..
```

Импорт прекращается при дубликатах, отрицательных значениях, пропусках или расхождениях сумм, требующих ручного решения. Изменение порядка/полей исходного CSV требует проверки схемы импорта.

## Формулы и семантика

- Расходы = Σ amount = Σ (price_discounted × quantity), только доставленные строки.
- Заказы = число уникальных order_id в отфильтрованных строках.
- Экономия = Σ ((price − price_discounted) × quantity).
- Средняя скидка = 100 × экономия / Σ (price × quantity). Это скидка, взвешенная по стоимости до скидки, а не простое среднее процентов. Поле discount содержит рубли на единицу.
- Средний чек = расходы / уникальные заказы. Для категории — расходы этой категории / заказы, содержащие эту категорию, а не весь чек таких заказов.
- Товары = Σ quantity без доставки и упаковки. Штука — позиция/упаковка, не граммы и не содержимое упаковки.
- Уникальные товары = число разных item_name без услуг. Категории = число категорий с доставленными строками, включая услуги.
- Цена товара за период/месяц = Σ amount / Σ quantity. Веса — купленные единицы. Это цена после скидки. Нет покупок — цена отсутствует, линия прерывается.
- Заказы разных категорий пересекаются. Складывать их числа нельзя. Расходы категорий складываются в общую сумму.
- Изменение показателя — к непосредственно предшествующему периоду той же длины в днях. Для скидки — процентные пункты; для остальных — проценты. Если предыдущий период выходит за начало источника, сравнение скрыто. Нулевая база не превращается в бесконечный рост.

Период влияет на KPI, рейтинги, категории, подсказки и графики. Блок обязательной динамики всегда сохраняет ось последних 24 месяцев, заканчивающихся месяцем последней записи (09.2024–08.2026); месяцы вне фильтра остаются без линии. Динамика категории показывает весь выбранный период. Внутри диапазона источника пустой месяц трактуется как отсутствие зафиксированных покупок (ноль); скидка и цена остаются неопределёнными. Полноту выгрузки вне известных данных проверить нельзя. Первый и последний месяцы неполные; август 2026 заканчивается 29 числа.

## Композиция и управление

Сначала можно выбрать неделю, месяц, квартал, год или весь период (по умолчанию год). Повествование раскрывается при прокрутке: сводка → ритм покупок → категории → лидеры товаров → история цены. Финальная кнопка открывает отдельный экран интерактивного дашборда: общая сводка → динамика → категории → ассортимент → раскрываемая методика. Общая сводка сохраняет контекст; выбор категории обновляет её подробные показатели, динамику и товары.

Два независимых рейтинга по штукам и расходам показывают разных лидеров. На каждой строке указано место товара в другом рейтинге. Для прямого сравнения одинаковых позиций переключите режим на лидеров по штукам или расходам. Топ-8/15/30/все, поиск и экспорт CSV помогают при большом ассортименте. Ширина каждой полосы нормируется на максимум соответствующего рейтинга; числовые значения и единицы подписаны.

Наведите на товар для подсказки с картинкой, категорией, количеством, расходами, заказами, средней ценой и помесячной ценой. Нажмите для закрепления; Esc или × закрывает. На телефоне работает нажатие.

Категорию можно выбрать на полосе или в таблице. KPI, товары и динамика пересчитаются; сравнение всех категорий сохраняется, выбранная выделяется. Таблица сортируется вместе с графиком. Есть индикатор и сброс. Услуги входят в расходы, но не в физический ассортимент.

## Проверки

`npm test`: контроль источника, взвешенная скидка/цена, пересечение заказов категорий, фильтры, 24-месячная ось, отсутствие покупки/цены, сопоставимый период, изображения, первая реальная строка.

Проверка браузера: рендер, подсказка/закрепление/Esc, выбор и сброс категории, период, поиск, услуги, сортировка, загрузка изображений, ширина мобильного экрана. Локальные скриншоты находятся рядом с папкой проекта.

## Плавная история и отдельная корзина

В начале доступны неделя, месяц, квартал, год и весь период. По умолчанию выбран год. Сроки отсчитываются включительно от последней записи (29.08.2026), а не текущего дня. Неделя — 7 дней; месяц/квартал/год — скользящее окно календарной длины с корректной обработкой конца месяца. Точные границы показаны пользователю. Для недели/месяца история использует дневную динамику, для более длинных сроков — месячную.

Главы раскрываются при прокрутке. Появление блоков не изменяет пропорции количественных отметок. prefers-reduced-motion отключает анимацию. После последней главы кнопка открывает отдельное представление полного дашборда (#dashboard) с выбранным периодом. Возврат к истории сохраняет выбор. Пока история открыта, дашборд не занимает место ниже страницы.
