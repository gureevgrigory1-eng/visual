# Проверка повествования и визуализации

Прочитаны все 17 слайдов файла `Неделя 4_Визуализация_Лекция_0175280e.pdf` и одностраничная шпаргалка. PDF состояли преимущественно из растровых изображений; проверка выполнена по рендерам страниц.

| Ошибка из лекции | Как исключена |
|---|---|
| Полосы оторваны от нуля | Шкалы категорий и товарных рейтингов линейные, domain начинается с 0. Длина равна значению / максимуму. |
| Сложение нескладываемого | Глобальные заказы считаются по Set(order_id). Заказы категорий не суммируются; объяснение в раскрываемом блоке. |
| Соединение несвязанного | Линии используются только для хронологического ряда месяцев. Категории и товары — отдельные полосы, без соединяющих линий. |
| Нарушение пропорций | Размер изображений фиксирован и не кодирует число покупок. Суммы кодируются длиной полосы, числовые подписи совпадают с метрикой. Нет произвольных размеров пузырей и 3D. |
| Двусмысленная палитра | Один постоянный цвет каждой категории во всех связанных блоках. Заказы — синий; расходы — оранжевый; скидка — фиолетовый. Цвет сопровождается подписью. |
| Ошибки компоновки | Сначала общая история, затем детали, затем интерактивный дашборд. Связанные подписи, единицы и графики находятся рядом. |
| Ложная интерпретация | Повествование описывает фактические покупки. Не утверждается причина изменений, инфляция или предпочтение пользователя на основе корреляции. Все числовые выводы пересчитываются из данных. |
| Неясные подписи | Рубли, штуки, заказы и проценты указаны около соответствующей метрики. Текст слева, числа справа. Денежные значения округлены для показа, расчёт ведётся в копейках. |
| Лишние чернила | Нет теней и 3D у количественных графиков, нет тяжёлых обводок и избыточной сетки. Фотографии помогают узнать ассортимент, а мягкие поверхности разделяют главы. |
| Нечитаемые оси | Графики измеряют собственную ширину через ResizeObserver. Подписи осей — 12 экранных пикселей, число подписей сокращается на телефоне. |
| Отсутствие данных подменено нулём | Цена и скидка при отсутствии покупок остаются null. Линия цены прерывается. Месяцы вне фильтра не соединяются. |

## Контрольный пример за 24 месяца

1. Сводка за 09.2024–08.2026: 343 заказа, 533109 ₽, 1911 шт., 412 товаров, скидка 1,8 %.
2. Максимальный месяц расходов — декабрь 2025, 59777 ₽. Это не автоматически самый частый месяц заказов.
3. Три крупнейшие категории дают 56,1 % расходов.
4. Лидер по штукам — Вода Шишкин лес, 74 шт.; лидер по деньгам — масло Вологодское, 26817 ₽ за 73 шт.
5. Покупная цена масла: 359 ₽ в первом наблюдаемом месяце, 399 ₽ в последнем; между ними показан реальный помесячный ряд.
6. Полный дашборд после истории: период, категории, сортировка, поиск, топ товаров, карточка товара и помесячная цена.
